# MAX Bot Moderator

Бот-менеджер для мессенджера MAX, который автоматически удаляет сообщения от пользователей, не являющихся администраторами чата.

## 🎯 Функционал

- ✅ Автоматическое удаление сообщений от не-админов
- ✅ Кэширование списка администраторов (обновление каждые 5 минут)
- ✅ Команды управления: `/help`, `/status`, `/myid`, `/refresh`
- ✅ Безопасное хранение токена (через переменные окружения)

## 🚀 Развертывание на BotHost.ru

### 1. Создайте бота на платформе MAX для партнёров
- Получите Bot Token

### 2. На BotHost.ru заполните форму:
- **Платформа:** Max
- **Библиотека:** Max Bot SDK
- **Bot Token:** ваш токен
- **Git URL:** `https://github.com/ваш_никнейм/max-bot-moderator`
- **Локация:** Россия (Москва)
- **☑️ Использовать домен** - ВКЛЮЧИТЕ!

### 3. Добавьте бота в чаты
- Добавьте бота в групповые чаты
- **Обязательно назначьте бота администратором!**

## 📋 Команды

- `/help` - Справка
- `/status` - Статус бота
- `/myid` - Узнать свой ID
- `/refresh` - Обновить список админов (только для админов)

## 🔒 Безопасность

Токен бота хранится в переменных окружения и НЕ содержится в коде!
